# AnderZilla Web

Games, AI and technology discovery platform built by Anderson Henrique Gonçalves.

**Live website:** [anderzilla.com](https://anderzilla.com)

## What it does

AnderZilla brings editorial discoveries, explainers and comparisons into a playful browsing experience, helping visitors explore games, AI, gadgets and technology in one place.

## Key features

- Topic-based discovery feed with search and source references
- Portuguese and English language options
- Saved discoveries (the visitor’s backpack) and interest personalization
- Exploration progress and quizzes
- Links to creator channels, products and sponsorship information
- StackPick and product discovery sections
